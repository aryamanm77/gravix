How to Install in Antigravity IDE

Get started in 3 simple steps without needing marketplace access.

Step 01
Download VSIX
Download the package via button or terminal curl.
Step 02
Install Extension
Windows: Ctrl + Shift + P → Install from VSIX, or PowerShell: code --install-extension gravix.vsix
macOS / Linux: Cmd + Shift + P → Install from VSIX, or Bash: code --install-extension gravix.vsix
Step 03
Enjoy Gravix
Select the downloaded file, reload your window, and find the Gravix icon in your Activity Bar!
