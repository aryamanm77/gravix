How to Install in Antigravity IDE

Get started in 3 simple steps without needing marketplace access.

Step 01
Download VSIX
Download the gravix-0.6.1.vsix file to your computer.
Step 02
Install from VSIX
In Antigravity IDE, press Ctrl + Shift + P and run Extensions: Install from VSIX...
Step 03
Enjoy Gravix
Select the downloaded file, reload your window, and find the Gravix icon in your Activity Bar!
